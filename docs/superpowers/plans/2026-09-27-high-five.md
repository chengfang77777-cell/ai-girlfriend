# High Five Implementation Plan

**Goal:** Implement the approved first touch interaction: raise a hand, wait for a palm tap, react briefly, and lower the arm. This is the first increment agreed in the preceding proposal; drinks and a desk scene are later increments.

**Architecture:** A deterministic local interaction timeline drives a normalized VRM arm pose layered over idle animation. A palm target is projected onto the canvas for hit testing. Flutter provides an accessible start/cancel control and receives state messages. No TTS requests or persistent relationship score.
