# 聊天背景动态效果

用户已授权自主选择最佳效果并实施。优化设置中已有的八种聊天背景，重点是人物所在的陪伴空间；继续使用暖白、鼠尾草绿和少量粉色的界面。

选择分层 Canvas 场景：与引入完整三维场景相比，能为已有 VRM 留出性能；与循环视频相比，能适应窗口尺寸、平滑切换和安静陪学。背景置于人物后方，不覆盖对话文字或拦截输入。

八种背景分别呈现夜色星河、柔光樱花、窗边暖光、流动色雾、草地萤光、黄昏云层、细雪远山、幽静极光。每种包含缓存的底色与景物、缓慢移动的光线、按深度变化的粒子；人物中心区域留出干净的视觉空间。取消高饱和色块和机械转动的射线。

动画按经过的时间推进，背景最多每秒绘制 30 次。限制像素与粒子数量，复用光点和花瓣贴图；改变窗口大小保持归一化的位置。切换背景用当前画面作为起点交叉淡入，连续切换不中断。指针产生极轻的光线视差。陪学专注时放慢动态，页面隐藏后暂停背景绘制。

原生验证发现当前 Windows 的减少动画偏好会使新版动效默认静止。为完成用户明确要求的动态优化，应用新增独立的背景动效选择，默认“舒缓动态”；同时提供“静态背景”和“跟随系统”。选择即时作用于现有网页并持久保存，系统偏好变化只能影响“跟随系统”。

验收：八种预设和旧别名均可用，未知背景安全回退；原生窗口实际展示并检查八种效果、人物可见性、切换、调整窗口、减少动画和陪学状态。回归人物动作、滚轮和学习状态。使用指定 Flutter SDK，在原 Release 目录编译正式 Windows 应用。
