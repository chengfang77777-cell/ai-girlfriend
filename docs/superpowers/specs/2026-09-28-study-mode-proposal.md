# 学习陪伴模式第一版方案（根据用户最新说明重写，待确认）

核心是安静陪伴、挫败时的理解和安抚，让用户更容易继续或安心休息。去掉讲题、拍题、测验、错题与课程功能。本方案尚未实现。

## 使用过程

进入“陪我学习”，可填写“今天想做什么”，也可不设目标直接开始。计时可选，不以倒计时或达标压力作为页面中心。人物保持自然呼吸、眨眼和轻微视线变化，不持续微笑，不定时说话打断学习。

页面保留“我学不下去了”“想休息一下”“今天先到这里”和自由输入。点击求安慰后暂停学习计时，展开简短对话：先针对用户刚说的困难回应，允许吐槽与沉默，再提供选择，不立即训话或催用户继续。用户可选择继续聊、安静陪着、休息，或者试着再做两分钟。

休息没有失败提示，也不产生欠下的时长。回到学习后保留原目标、已学时长和草稿。退出时可以留一句“下次从这里继续”，下次进入再接上。

## 有真实感的回应

- **具体回应**：根据本次目标、真实学习时长、用户明确说过的卡点和最近对话回应，不靠固定鸡汤。没有观察到的信息不假装知道。
- **先陪伴再商量**：例如用户说“看半天也看不懂”，先回应“卡在这里这么久，确实会烦。先不用逼自己马上弄懂，想跟我说说，还是先歇一会儿？”用户愿意继续后再一起选一个很小的下一步。
- **区别疲劳和挫败**：用户说累了，允许休息；说自责，回应那份自责；说无聊，尝试轻松一点的语气。没有用户线索时不替用户判断情绪。
- **保留人物性格**：温柔角色更轻柔，活泼角色可以有克制的幽默，但不会嘲讽、不耐烦或用内疚感逼用户学习。
- **表情和话相符**：倾听时中性或轻微关切，鼓励时短暂柔和表情。用户难受时不自动笑，不每句话都配夸张动作。自然停顿通过短句和等待回应体现，不故意延迟网络请求。
- **连续性**：记住本次对话刚刚提到的困难；跨次保存只包含用户主动留下的目标与“下次从哪里继续”，可查看和删除。

## 第一版实现范围

独立的 Windows 陪学页，人物为主体，低存在感的目标/计时和陪伴按钮。四个状态：安静学习、倾诉安抚、休息、结束。开始、暂停、返回与记录均在本地运行，不依赖 AI 服务；重启后恢复为暂停状态，最小化时已启动的学习计时继续。

安抚对话复用当前人物、现有模型供应商及音色配置，增加独立陪学提示词和会话上下文。文字先显示；语音遵循现有播放偏好，合成失败不阻塞文字和陪伴状态，并保留草稿与重试入口。此功能不自行更改已有语音超时策略。

默认不主动打断。用户点击求安慰、发消息或完成自己设定的时段时才触发回应。不给用户的情绪打分，不因提前结束扣分，也不通过摄像头、屏幕或键盘停顿推断用户是否认真。

## 验收

检查安静状态没有主动语音与夸张动作；疲劳、自责、烦躁等示例能得到贴合上下文的回应；相邻对话不重复固定鼓励；表情短暂且与内容相符；返回学习不丢目标和草稿；离线仍能计时和休息；网络失败不出现无提示等待；提前结束没有指责或处罚；记录可删除。

按用户先确认再实施的要求，本版范围确认后再开发。
