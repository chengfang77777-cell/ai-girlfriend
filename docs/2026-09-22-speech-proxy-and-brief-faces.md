# Windows 语音超时与短暂自然表情

本次修正替代 2026-09-21 版本的持续情绪方案。

后续表情可见性回归及语音诊断见 [表情时序回归与语音诊断](2026-09-22-expression-timing-and-tts-diagnosis.md)。下列表情强度及仅文字触发的描述属于前一版。

## 语音定位

之前 Flutter 测试进程的短句请求成功，不能证明发布 EXE 的网络也正常。本次将同一角色、同一已存音色样本放进 Windows Release 运行：原客户端在 30 秒后超时。电脑启用了 Windows 手动系统代理，发布程序原来的 Dart HTTP 客户端没有自动遵循该设置。

指定当前系统代理后，同样的发布进程请求成功（一次约 8.6 秒）；实现自动读取系统设置后，一次约 4.6 秒。耗时取决于代理线路与语音服务，不代表每次延迟保证。

随后发布进程连续验证：第一条约 5.9 秒成功，后两条收到服务端 HTTP 429（限流或额度限制，其中一条在重连后返回）。已停止继续真实调用。应用现在能给出明确提示，但不能消除服务端限流；不能把本次结果表述为所有语音请求均成功。

- 新客户端读取 Windows 当前用户的 ProxyEnable、ProxyServer、ProxyOverride，支持通用代理与按 HTTP/HTTPS 配置的代理，尊重本地/通配符例外。
- 不硬编码本机端口，不改写系统代理设置；不开代理时正常直连。当前支持手动系统代理，未新增 PAC 自动配置解析。
- 每次合成连接设有连接超时；超时、切换角色、停止语音都会关闭旧连接，避免遗留请求继续占用网络。
- 短暂连接错误或超时最多自动重连一次，保留原文本和固定音色参考。认证及服务端错误不盲目重试。单次合成仍有 30 秒上限，两次都失败后明确提示。
- 重连期间界面显示“语音连接较慢，正在重新连接…”。

## 表情行为

- 启动及切换角色默认中立，加载历史聊天不会重放旧表情。
- 新回复只触发一次对应表情；连续相同情绪的回复仍可分别触发。
- 八种情绪均降低强度、减少不协调的多通道叠加，移除整张脸周期性强弱变化。
- 保持约 1.5 秒，再用约 1.8 秒渐变收回；约 4 秒完全中立。使用实际时间计时，渲染变慢或窗口暂时停绘不会延长笑脸。
- 说话期间进一步降低影响嘴部的情绪权重，长语音也不保持整段微笑。
- 提示词允许普通、温暖的回复选择 neutral；不再因“爱好”“没有笑”“不开心”等词强制改成 happy。
